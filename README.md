# Hard-Insert

VST3-плагин для работы с физическим аппаратным компрессором через аудиоинтерфейс (ASIO).
Звук трека уходит на выход интерфейса, проходит через устройство и возвращается на вход интерфейса.

## Функции

- **Input Trim / Output Trim** (±24 дБ) — подгонка уровня перед устройством и после возврата.
- **Force Mono** — сумма L+R в `(L+R)/2` и отправка через один канал. Экономит физические каналы.
- **Measure Latency** — один импульс через петлю, измерение задержки устройства и передача её хосту (PDC). Значение хранится отдельно для каждой частоты дискретизации и сохраняется в проекте.

## Сборка

Сборка выполняется в GitHub Actions на `windows-latest` (см. `.github/workflows/build.yml`).
Готовый `Hard-Insert.vst3` доступен в artifacts каждого запуска.

Локально (Windows, Visual Studio 2022):

```
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

## Настройка в FL Studio 21

1. Добавить плагин в микшерный трек. Для стерео-режима включить два выхода/входа, для моно — один.
2. Назначить Send-выход на физический канал интерфейса, Return-вход — с физического канала возврата.
3. Нажать **Measure Latency** с подключённой петлёй.

Подробности по маршрутизации в FL пока проверяются, см. историю коммитов.
